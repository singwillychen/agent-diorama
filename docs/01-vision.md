# 01 · 願景與視覺規格

## 設計原則

1. **事件驅動，不演戲** — 每個「工作中」的動作都對應一個真實事件（思考、工具呼叫、傳訊、錯誤）。閒置時播放閒置動畫，並與工作狀態有明確視覺差異，視覺永遠不誤導使用者。
2. **一份資料，三種皮** — 三個場景共用同一套事件流與角色分類，只換外觀。同一個 agent 跨場景保留臉孔與髮型，只換服裝，建立「這是同一個人」的認知。
3. **框架中立** — 場景與面板只認標準化事件協定（見 [06](06-integration-protocol.md)）。
4. **語意縮放（Semantic Zoom）** — 拉遠看全局狀態與熱度，拉近看對話細節。
5. **資料驅動、可覆寫** — 一切外觀與行為規則皆可由設定檔調整（見 [07](07-extensibility.md)）。

## 鏡頭

| 項目 | 規格 |
|---|---|
| 俯角 | 預設 60°（可在 45°–70° 微調） |
| 投影 | 透視投影，窄 FOV（約 30°）以接近等角的微縮感 |
| 旋轉 | 水平 ±30°，避免看到場景「背面」 |
| 縮放 | 3 段語意縮放：全景／區域／個人 |
| 效果 | 輕微 tilt-shift 景深，強化「桌上模型」感；可關閉 |
| 跟隨 | 點選 agent 後鏡頭平滑跟隨；發生警報時可自動飛到事發位置（可關） |

## 畫風

- **寫實材質 + Q 版比例**：參考「黏土人／figma 公仔實拍」——PBR 布料、皮革、金屬、皮膚 SSS，加上寫實光影與環境光遮蔽。
- **3–4 頭身全身角色**：頭部大、五官清楚，確保 60° 俯角下仍能讀出表情。
- **表情系統**：眼、眉、嘴以 blendshape 或貼圖切換，至少涵蓋：平靜、專注、開心、困惑、焦慮、驚嚇、得意、疲倦。

## 角色系統（模組化）

```
Base Body (共用骨架 / Humanoid rig)
 ├─ head      頭型
 ├─ face      五官 + 表情集
 ├─ hair      髮型（跨主題保留）
 ├─ outfit    服裝（依主題 × 職能）
 ├─ accessory 配件（耳麥、拂塵、筆電…）
 ├─ badge     職級標誌（肩章／名牌／道袍色）
 └─ prop      手持道具（依狀態切換）
```

- 格式：glTF 2.0 / GLB；動畫名稱統一（見 [07](07-extensibility.md) 的資產契約）。
- 職級視覺：可由模型等級、資歷或使用者自訂決定（例：修仙世界的「境界」）。
