# 08 · 延伸構想

1. **使用者化身** — 你也是場景中的角色（司令／老闆／宗主）。走到 agent 旁點擊即可對話；把任務卡拖到 agent 身上即指派。
2. **時光回放與精華剪輯** — 所有事件存檔，可拖時間軸、倍速回放；自動剪出「本次任務精華」供檢討或分享。
3. **空間即資訊** — 會議室 = 討論中、茶水間 = 閒置、伺服器室 = 執行工具；看站位就能判讀全局。
4. **動態增減員** — sub-agent 從門口走進或傳送陣降臨，結束後離場；50+ agent 時自動擴樓層／山峰，並用 LOD。
5. **預算實體化** — 靈石堆、油料表、咖啡罐實際減少，一眼看出還剩多少錢。
6. **迴圈與失控偵測** — 偵測兩個 agent 反覆來回、重複呼叫同一工具，畫面出現「鬼打牆」提示並可一鍵中止。
7. **隱私／展示模式** — 自動遮蔽祕密資訊；展示模式只顯示摘要，適合截圖、直播。
8. **場景外通知** — agent 等你核准時推播到桌面或手機。
9. **音效設計** — 每個主題有環境音與事件音，不看畫面也能「聽」出狀態；支援空間音效。
10. **場景 SDK** — 開放社群做第四、第五個場景（太空站、醫院、海賊船…）。
11. **編制比較實驗** — 同一任務用不同團隊編制各跑一次，並排比較成本、時間、品質。
12. **觀戰與多人** — 團隊成員可同時觀看同一世界，分享連結唯讀觀戰。
13. **無障礙與效能退路** — 色盲友善、減少動態、純文字模式；低階裝置自動降為 2.5D。
14. **情緒與疲勞（需謹慎）** — context 接近上限時角色顯得疲倦、連續失敗時焦慮；必須完全由指標推導，並可關閉。
