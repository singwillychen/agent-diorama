# 03 · 三大場景

每個場景都由 **區域（zone）**、**席位（seat）**、**道具（prop）** 與 **狀態光（ambient state）** 組成。區域有語意：agent 站在哪裡本身就是資訊。

## ⚓ 1. CIC 戰情中心

**空間與區域**

| 區域 | 語意 |
|---|---|
| 指揮台（高處） | orchestrator 席位 |
| 階梯式控制台 | 各職能工作席 |
| 中央全息戰術桌 | 任務 DAG 立體投影；`meeting` 狀態聚集處 |
| 牆面戰情大螢幕 | 嵌入 Mod 面板 |
| 通信室 | communicator、對外 API 呼叫 |
| 走廊／艙門 | sub-agent 進出場 |
| 茶水角 | `idle` |

- **服裝**：海軍藍工作服、耳機麥克風、肩章、職務臂章。
- **溝通**：耳麥光束連線；字幕採無線電格式（「作戰官，收到，執行中。」）。交接時傳令兵實際走過去遞交公文夾。
- **狀態光**：🟢 Condition Green 正常 → 🟡 Yellow 有人卡住／等人類 → 🔴 Red 錯誤或超出預算（旋轉警示燈、全員抬頭）。
- **音效**：聲納聲、無線電雜訊、警報。

## 💻 2. 新創公司辦公室

| 區域 | 語意 |
|---|---|
| 開放座位區 | 一般工作 |
| 角落獨立辦公室 | orchestrator |
| 玻璃會議室 | `meeting` |
| 白板牆 | 任務看板實體化 |
| 咖啡吧／懶骨頭 | `idle` |
| 伺服器機櫃角 | `tool_call`（重型工具、部署） |
| 電話亭 | `long_running`、專注模式 |
| 大門 | 新進／離開 |

- **服裝**：帽 T、格紋襯衫、牛仔褲、耳機、貼滿貼紙的筆電。
- **溝通**：Slack 風對話泡泡；配對作業時把椅子拉到同桌。
- **趣味映射**：咖啡杯數 = token 燃燒率；任務久未完成時桌上披薩盒疊高；部署成功有人敲鑼；窗外日夜依真實時間變化。

## ⛰️ 3. 修仙山門（參考《凡人修仙傳》氛圍，造型原創）

| 區域 | 語意 |
|---|---|
| 主峰議事大殿 | orchestrator、`meeting` |
| 藏經閣 | 知識庫／RAG／記憶讀寫 |
| 煉丹房／煉器房 | builder 產出程式或檔案 |
| 洞府（側峰） | `long_running` 閉關 |
| 傳送陣 | sub-agent 降臨與離去 |
| 護山大陣 | 安全、權限、稽核 |
| 靈獸園／雲台 | `idle` |
| 山門牌坊 | 對外通訊 |

- **服裝**：寬袖道袍、髮冠、拂塵、飛劍、儲物袋；依境界換袍色與周身靈光。
- **溝通**：傳音符（紙符化流光飛行）；廣播 = 千里傳音光環。
- **概念映射**：

| 系統概念 | 修仙對應 |
|---|---|
| token 成本 | 靈石 |
| context window | 神識／丹田容量 |
| 錯誤 | 走火入魔（黑氣） |
| 重試 | 再次閉關 |
| 任務完成 | 突破（光柱） |
| 權限拒絕 | 撞上禁制 |
| 外部 API | 坊市交易 |

- **音效**：古琴、鐘聲、風聲、鶴鳴。
