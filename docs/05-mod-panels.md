# 05 · Mod 面板系統

面板是 **外掛（mod）**：可安裝、啟用、排列、換皮。每個面板訂閱事件流，並依當前主題的 design token 自動換皮。

## 主題換皮

| 主題 | 面板風格 |
|---|---|
| CIC | 綠／琥珀磷光戰術 HUD、等寬字體、掃描線 |
| 辦公室 | 乾淨 SaaS 卡片、圓角、柔和陰影 |
| 修仙 | 玉簡／卷軸、宣紙紋理、篆隸標題、印章式徽章 |

## 內建面板

| 面板 | 讓使用者知道什麼 | 優先 |
|---|---|---|
| **Agent 名冊** | 角色、模型、廠商、狀態、目前任務、在線時間 | P1 |
| **任務看板／DAG** | 任務拆解、依賴、負責人、進度 | P1 |
| **對話時間軸** | agent 間完整訊息流，可篩選、搜尋 | P1 |
| **人類審批佇列** ⭐ | 所有等你決定的事集中處理（核准／駁回／修改） | P1 |
| **Token 與成本** | 個別與整體花費、燃燒率、預算剩餘、預估完成成本 | P1 |
| **警報中心** | 錯誤、重試、逾時、超預算、迴圈偵測 | P2 |
| **Context 使用率** | 每個 agent 的 context window 水位 | P2 |
| **工具呼叫追蹤** | 工具名稱、參數、耗時、結果 | P2 |
| **產出物** | 檔案、diff、報告預覽 | P2 |
| **組織樹** | 誰派生了誰（sub-agent 階層） | P3 |
| **記憶／知識** | 共享記憶與知識庫讀寫紀錄 | P3 |
| **權限稽核** | 高風險操作與資源存取紀錄 | P3 |
| **效能** | 延遲、吞吐、模型 API 錯誤率 | P3 |

## 版面預設（Layout Presets）

| 預設 | 內容 |
|---|---|
| 指揮官視圖 | KPI 列、警報、審批佇列、名冊 |
| 除錯視圖 | 工具追蹤、對話時間軸、context |
| 老闆視圖 | 成本、進度、產出物 |
| 禪模式 | 關閉面板，只看場景（第二螢幕「工作水族箱」） |

## 面板外掛 API（草案）

```ts
export default definePanel({
  id: "cost-meter",
  title: { "zh-TW": "成本", en: "Cost" },
  subscribe: ["cost.updated", "agent.registered"],
  defaultSize: { w: 4, h: 3 },
  settings: { budgetUsd: { type: "number", default: 10 } },
  render: ({ state, theme, settings }) => /* 使用 theme.tokens 取色 */ null,
  // 選用：面板可在場景中放置對應的實體道具（例如牆上螢幕）
  sceneAnchor: "wall_display_main",
});
```

面板只讀世界狀態；需要改變世界時（核准、暫停）透過 `commands` 送出指令，由協定層轉發給 agent 系統。
