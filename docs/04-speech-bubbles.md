# 04 · 對話文字泡泡（Speech Bubbles）

角色頭上會冒出自己的文字泡泡。泡泡分成兩大類：**事件驅動（忙碌中）** 與 **閒置台詞（沒事時）**。設計重點是「有生命感」，但 **絕不讓閒聊被誤認為真實工作**。

## 泡泡類型

| 類型 | 來源 | 外觀 | 範例（辦公室） |
|---|---|---|---|
| 💬 **工作泡泡** `work` | 事件驅動（工具呼叫、任務進度） | 實心白底、左側事件圖示、粗字 | 「🔍 正在搜尋 auth 相關檔案…」 |
| 🗨️ **對話泡泡** `dialogue` | agent 間訊息 `message.sent` 摘要 | 實心＋指向對象的尾巴／連線 | 「@Alice 這個 API 我改好了，幫我看一下」 |
| 💭 **思考泡泡** `thought` | `thinking` 狀態；可用 agent 提供的推理摘要 | 雲朵形、半透明 | 「嗯…先確認 schema 再動手」 |
| ❗ **警示泡泡** `alert` | `error`、`waiting_human`、超預算 | 主題警示色、閃爍邊框、**常駐直到處理** | 「需要你核准：刪除 3 個檔案」 |
| 🎐 **閒置泡泡** `idle` | 主題台詞池（不對應事件） | **淡色、斜體、較小、無圖示**、自動淡出 | 「今天的咖啡好像比較淡…」 |
| 🎭 **閒聊對話** `banter` | 兩個 idle agent 之間的短劇本 | 同 idle 樣式，兩人輪流 | A：「午餐吃什麼？」B：「等 CI 跑完再說。」 |
| 📢 **系統旁白** `narrator` | 世界事件（新 agent 入場、階段完成） | 置於畫面頂部或場景中央的橫幅 | 「⛰️ 新弟子自傳送陣降臨」 |

> **誠實原則**：`idle` 與 `banter` 一律使用「淡、斜、無圖示」的樣式，且只在 agent 真的處於 `idle` 時出現。工作與閒聊在 0.5 秒內必須能被一眼區分。

## 文字來源（依優先序）

1. **Agent 自述** — 事件可附 `utterance` 欄位，由 agent 自己提供一句話（最真實）。
2. **事件模板** — 依事件類型＋主題＋職能套模板，例如：
   - `tool.called(name=grep)` → 辦公室：「翻一下 `{args.pattern}` 在哪」／CIC：「情報檢索：{args.pattern}」／修仙：「神識掃過藏經閣，尋『{args.pattern}』」
3. **主題台詞池** — 依 `theme × role × state` 隨機挑選（見 `themes/*/bubbles.zh-TW.json`）。
4. **（選用）LLM 角色化改寫** — 用小模型把原始摘要改寫成角色口吻；有快取、每分鐘上限與成本上限，失敗時退回模板。

模板變數：`{agent.name}` `{agent.title}` `{target.name}` `{tool.name}` `{args.*}` `{task.title}` `{cost}` `{duration}` `{time_of_day}`。

## 閒置台詞的情境感知

閒置台詞不是純隨機，而是參考最近的世界狀態：

| 情境條件 | 範例（修仙） |
|---|---|
| 剛從 `error` 恢復 | 「好險…差點走火入魔。」 |
| 長時間沒任務 | 「掌門今日似乎無事交代。」 |
| 預算消耗 > 80% | 「靈石所剩不多了啊…」 |
| 深夜 | 「月色正好，適合參悟。」 |
| 同伴剛完成任務 | 「師兄又突破了，真令人羨慕。」 |
| 自己連續完成多個任務 | 「今日狀態極佳！」 |

條件以 `when` 規則宣告（例：`{"recent": "error_resolved", "within": "60s"}`），由引擎評估。

## 密度與節奏控制

| 規則 | 預設值 | 說明 |
|---|---|---|
| 同時可見泡泡上限 | 6 | 超過時依優先序排隊 |
| 優先序 | alert > dialogue > work > thought > narrator > banter > idle | |
| 停留時間 | `1.5s + 0.25s × 字數`（中文）／上限 8s | alert 常駐直到處理 |
| 單一 agent 冷卻 | work 1.5s、idle 20–60s 隨機 | 避免洗版 |
| 全場閒置台詞頻率 | 每 8–15 秒最多 1 則 | 可在設定調整「熱鬧度」 |
| 長度上限 | 工作 30 字、閒置 20 字 | 超過截斷加「…」，點擊展開 |
| 碰撞避讓 | 泡泡自動上下錯位，不遮擋臉 | |
| 語意縮放 | 全景：只顯示 alert 圖示；區域：顯示工作與對話；個人：全部 | |

## 互動

- **點泡泡** → 跳到對話時間軸／工具追蹤面板的對應事件。
- **懸停** → 顯示完整文字與時間戳。
- **釘選** → 保留在畫面上。
- **靜音某 agent 的閒置台詞**、或全域「專注模式」關閉 idle／banter。

## 隱私與安全

- 顯示前經過 **遮蔽管線**：API key、token、email、電話、信用卡號等 pattern 自動替換為 `•••`。
- **展示模式**：工作泡泡只顯示「動作類型」而不顯示參數（例：「正在搜尋檔案」）。

## 多語系

台詞檔依語系分檔：`bubbles.zh-TW.json`、`bubbles.en.json`…；缺漏時回退至 `_base` 主題同語系，再回退至英文。
