# 02 · 角色與狀態

## 通用職能分類

agent 的「職能（role）」是抽象層，各主題再映射成自己的身分。外部 agent 只需在 manifest 宣告 `role`，即可自動被放進任何主題的正確位置。

| 通用職能 `role` | CIC 戰情中心 | 新創辦公室 | 修仙山門 |
|---|---|---|---|
| `orchestrator` 總指揮 | 艦長／指揮官 | CEO / PM | 掌門 |
| `planner` 規劃 | 副艦長 XO | Tech Lead | 執法長老 |
| `researcher` 研究 | 情報官 | 研究員／分析師 | 藏經閣守閣長老 |
| `builder` 執行 | 作戰官／武器官 | 工程師 | 煉丹師／煉器師 |
| `reviewer` 審查 | 值更官 | QA | 戒律堂長老 |
| `monitor` 監控 | 雷達／聲納官 | DevOps / SRE | 護山大陣陣法師 |
| `communicator` 對外 | 通信官 | 業務／客服 | 外事執事 |
| `designer` 設計 | 作戰圖繪製官 | 設計師 | 符籙師 |
| `subagent` 臨時工 | 傳令兵 | 實習生 | 外門弟子 |
| `human` 使用者本人 | 司令 | 老闆／創辦人 | 宗主／太上長老 |

未知職能會落到 `builder` 預設席位，並顯示原始 role 名稱。

## 職級（rank）

`rank` 可為 1–9 的數字，或由模型能力自動推得。主題各自定義呈現：

| rank | CIC 肩章 | 辦公室 | 修仙境界 |
|---|---|---|---|
| 1–2 | 士兵 | Intern | 煉氣期 |
| 3–4 | 士官 | Junior | 築基期 |
| 5–6 | 尉官 | Senior | 結丹期 |
| 7–8 | 校官 | Staff / Principal | 元嬰期 |
| 9 | 將官 | C-level | 化神期 |

## 通用狀態

| 狀態 `state` | 觸發事件 | CIC | 辦公室 | 修仙 |
|---|---|---|---|---|
| `idle` 閒置 | 無進行中工作 | 喝咖啡、整理桌面 | 滑手機、去茶水間 | 賞雲、餵仙鶴 |
| `thinking` 思考 | LLM 推論中 | 盯螢幕、手指敲桌 | 托腮、頭上「…」 | 盤坐吐納，靈氣環繞 |
| `tool_call` 用工具 | 工具執行中 | 操作控制台、螢幕閃動 | 狂打鍵盤 | 掐訣施法、法器發光 |
| `speaking` 傳訊 | 發送訊息 | 按耳麥說話 | 對話泡泡 | 傳音符化流光飛出 |
| `listening` 接收 | 收到訊息 | 側耳聆聽 | 轉頭看 | 玉簡亮起 |
| `meeting` 討論 | 多 agent 同一議題 | 聚到戰術桌 | 走進會議室 | 聚於議事大殿 |
| `waiting_human` 等人類 | 需核准／輸入 | 舉手、頭頂黃燈 | 舉手看向鏡頭 | 跪地請示、玉簡閃爍 |
| `blocked` 卡住 | 依賴未完成／逾時 | 抱頭看地圖 | 趴桌 | 眉頭緊鎖、靈氣停滯 |
| `error` 錯誤 | 例外／失敗 | 紅燈警報 | 螢幕藍屏冒煙 | 走火入魔、冒黑氣 |
| `retrying` 重試 | 重新嘗試 | 重新校準 | 重開機 | 再次閉關 |
| `long_running` 長任務 | 執行超過門檻 | 進入作戰室 | 戴降噪耳機 | 入洞府閉關 |
| `done` 完成 | 任務完成 | 敬禮 | 擊掌 | 突破光柱 |
| `offline` 離線 | 斷線 | 座位空、螢幕暗 | 外出牌 | 座位化為石像 |

狀態轉換規則與動畫混合時間可在主題中覆寫。
